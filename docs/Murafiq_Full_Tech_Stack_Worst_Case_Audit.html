4. Four Core Architectural Circuit Breakers Protecting Capital

1. Atomic CAS Daily Quotas

All message limits are metered by atomic Compare-And-Swap ($inc with used <= limit - count) in Cairo business timezone. Prevents race-condition spikes and bounds daily financial liability to small fractions of a dollar.

2. In-Memory Image Pre-Compression

Before any photo reaches Cloudinary or Gemini Vision, the upload service compresses images in-memory via Sharp. This shrinks payload sizes by 75–85%, keeping Cloudinary credit burn safely inside standard plan limits.

3. 24h Redis Shopping Cache

Common wardrobe gaps (e.g. "navy formal trousers", "white sneakers") are stored in Redis for 24 hours. When multiple users ask for similar occasions, Serper API queries are bypassed, slashing search costs by 50–70%.

4. Google Hard Billing Ceiling

By establishing a monthly hard budget cutoff (e.g. $2,000 USD) in Google Cloud Console, the Gemini API automatically refuses excess calls before unexpected cloud debt can ever accumulate.
